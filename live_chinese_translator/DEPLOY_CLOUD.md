# ☁️ Размещение в облаке (бесплатно, 24/7)

Этот документ объясняет, как разместить **панель студента + математический ассистент Xiao Shu** в интернете бесплатно и круглосуточно, **без включения вашего компьютера**.

## Гибридная схема (Вариант A — два адреса)

| Что | Где | Когда работает |
|-----|-----|----------------|
| Панель студента `/student` + ассистент Xiao Shu + история + верификация + WebRTC | **Облако** (Railway/Render/Fly.io) | **24/7, бесплатно** |
| Живая лекция с распознаванием речи преподавателя | **Ваш Mac** + ngrok | Только во время лекции |

> ⚠️ **Почему так?** Распознавание речи использует **локальный микрофон** вашего Mac ([`app.py`](app.py:943)). Микрофон — физическое устройство, его нельзя перенести в облако. Поэтому живая лекция всегда требует вашего компьютера, но **ассистент Xiao Shu и панель студента доступны всегда**.

## Шаг 1. Подготовка файлов

Уже созданы:
- [`Procfile`](Procfile) — команда запуска для облака
- [`requirements-cloud.txt`](requirements-cloud.txt) — облегчённые зависимости (без микрофона/экрана)
- [`.env.example`](.env.example) — шаблон переменных окружения
- [`app.py`](app.py) — адаптирован: в облачном режиме (`CLOUD_MODE=1`) не запускает захват микрофона

## Шаг 2. Выбор хостинга (бесплатно)

Рекомендую **Railway** (проще всего) или **Render** (стабильный бесплатный тариф).

### Вариант 2.1 — Railway (рекомендую)
1. Зарегистрируйтесь на https://railway.app (бесплатно, ~$5 кредита в месяц хватает)
2. Нажмите **New Project → Deploy from GitHub repo**
3. Подключите репозиторий с этим проектом (нужно загрузить код на GitHub)
4. Railway сам найдёт `Procfile` и `requirements-cloud.txt`
5. В **Variables** добавьте переменные из [`.env.example`](.env.example):
   - `CLOUD_MODE=1`
   - `DEEPSEEK_API_KEY=ваш_ключ`
   - `TURN_USERNAME`, `TURN_CREDENTIAL`, `TURN_URLS` (из вашего `.env`)
   - `SESSION_SECRET`, `GEO_SECRET_KEY`
   - `ARCHIVE_DIR=archive` (папка архива лекций)
   - `ARCHIVE_UPLOAD_KEY=придумайте_секретный_ключ` (для загрузки лекций с Mac)
6. Railway выдаст публичный URL (например `https://xxx.up.railway.app`)

### Вариант 2.2 — Render
1. Зарегистрируйтесь на https://render.com
2. **New → Web Service → Connect GitHub repo**
3. Build Command: `pip install -r requirements-cloud.txt`
4. Start Command: `gunicorn -w 1 --threads 8 --bind 0.0.0.0:$PORT app:app`
5. В **Environment** добавьте те же переменные (см. выше)
6. Render выдаст URL (например `https://xxx.onrender.com`)

### Вариант 2.3 — Fly.io
1. Установите `flyctl` и войдите: `fly auth login`
2. В папке проекта: `fly launch`
3. Создайте `fly.toml` с `[env] CLOUD_MODE = "1"` и остальными переменными
4. `fly secrets set DEEPSEEK_API_KEY=... TURN_USERNAME=...`
5. `fly deploy`

## Шаг 3. Проверка облака

После деплоя откройте публичный URL:
- `https://ВАШ-URL/student` — панель студента (работает 24/7)
- `https://ВАШ-URL/` — панель преподавателя (без распознавания в облаке)
- Ассистент Xiao Shu доступен всегда

> 💡 **Важно:** в облаке нет микрофона, поэтому распознавание речи там не работает. Это нормально — оно работает на вашем Mac во время лекции.

## Шаг 4. Живая лекция (на вашем Mac)

Когда вы ведёте лекцию:
1. Запустите сервер на Mac как обычно: `./manage_shunyi.sh start`
2. Запустите ngrok: `./manage_shunyi.sh ngrok` (или через launchd)
3. Студенты подключаются к ngrok-адресу для живой трансляции

---

## Итог

- **Вне лекции:** студенты заходят на облачный URL — ассистент Xiao Shu и панель доступны 24/7
- **Во время лекции:** студенты заходят на ngrok-адрес вашего Mac — живая трансляция с распознаванием

Оба адреса работают параллельно. Облако не требует вашего компьютера.

## 🗂 Архив лекций (прошедшие уроки)

Студенты могут **просматривать прошедшие уроки** в любое время через кнопку **«🗂 Archive»** на панели студента (`/student`).

### Как это работает (автоматическая синхронизация Mac → облако)

1. **На Mac** при завершении работы сервера (Ctrl+C / остановка) лекция автоматически отправляется в облако через `POST /api/archive/upload`.
2. **В облаке** лекция сохраняется как JSON-файл в папке `ARCHIVE_DIR`.
3. **Студенты** открывают архив через кнопку «🗂 Archive» — видят список прошедших уроков и могут открыть любой из них (полный текст + перевод).

### Настройка

| Переменная | Где | Что задаёт |
|------------|-----|------------|
| `ARCHIVE_DIR=archive` | **Облако** | Папка хранения архива |
| `ARCHIVE_UPLOAD_KEY=...` | **Облако и Mac** (одинаковый!) | Секретный ключ для загрузки/удаления |
| `CLOUD_ARCHIVE_URL=https://xxx.up.railway.app` | **Только Mac** | Публичный URL облака, куда Mac отправляет лекции |

> ⚠️ **Важно:** `ARCHIVE_UPLOAD_KEY` должен быть **одинаковым** на облаке и на Mac, иначе Mac не сможет загрузить лекцию в архив. `CLOUD_ARCHIVE_URL` задаётся **только на Mac** (в облаке он не нужен).

### API архива

- `GET /api/archive` — список прошедших лекций
- `GET /api/archive/<id>` — полное содержимое лекции
- `POST /api/archive/upload` — загрузка лекции (защищено ключом, используется Mac)
- `DELETE /api/archive/<id>` — удаление лекции (защищено ключом)
